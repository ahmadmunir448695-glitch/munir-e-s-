# Munir Electric Store — Website

Frontend-only product catalogue for **Munir Electric Store** (Phone / WhatsApp **0308-3380368**).
**Live site:** https://phenomenal-baklava-e95a2d.netlify.app (Netlify, rebuilds automatically on every push to `main`)
· Mirror: https://ahmadmunir448695-glitch.github.io/munir-e-s-/

Built with **Vue 3 + Vite + Tailwind CSS** (plain JavaScript). There is no backend: customers browse products and send inquiries on WhatsApp.

## Run it

```bash
npm install
npm run dev        # opens on http://localhost:5173
npm run build      # production files in dist/
npm run preview    # preview the production build
```

## Where to edit things

| What | File |
|---|---|
| Phone, WhatsApp number, address, map link, business hours | `src/data/store.js` |
| Products: names, prices, variants, specs, images | `src/data/products.js` |
| Categories | `src/data/categories.js` |
| Colours & fonts (orange / charcoal theme) | `src/assets/main.css` (the `@theme` block) |
| WhatsApp message wording | `src/utils/whatsapp.js` |

**WhatsApp number:** 0308-3380368 in international format is `923083380368` (drop the leading 0, add 92). All WhatsApp links use `https://wa.me/923083380368` with a pre-filled message such as:
*"Assalam o Alaikum, I am interested in Indus Ceiling Fan 56" (56" (Large rooms), White). Please share price and availability."*

### Replacing product images
Demo illustrations are in `public/images/products/` (generated by `npm run images`). To use real photos, either:
- save your photo with the **same file name** (e.g. `fan-royal.svg` → keep the name, or change the extension in `products.js`), or
- put any image in `public/images/` and change that product's `image` path in `src/data/products.js`.

Square images (e.g. 800×800) look best. If an image is missing, a neutral "Image coming soon" placeholder is shown.

### Adding a product
Copy any product block in `src/data/products.js`, give it a new unique `id`, and set its `category` to one of the category slugs. `variants` (with prices) and `options` (like colour) are optional.

## Features
- Pages: Home, Products, Product details, Categories, About, Contact (+ 404)
- Product search (ranked: name matches first), category filters, sorting, shareable filter URLs
- Variants with prices, options (colour / base / finish), quantity, related products
- WhatsApp inquiry on every product card and page, floating WhatsApp button, call buttons
- Contact form that opens WhatsApp with the message (no server needed)
- Sticky header, mobile hamburger menu & search, scroll-to-top, page transitions, empty search state
- Responsive: 2 products per row on phones, up to 4 on desktop

## Live on GitHub Pages (free)

The `docs/` folder is a ready-built copy of the site for GitHub Pages: **https://ahmadmunir448695-glitch.github.io/munir-e-s-/**

To turn it on (once): repo **Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/docs` → Save**.

After editing the site, rebuild and push:
```bash
npm run build:pages
git add -A && git commit -m "Update site" && git push
```
The base path (`/munir-e-s-/`, the repo name) is set in `scripts/build-pages.js`. If you rename the repo, change it there.

## Deploying elsewhere
`npm run build` and upload `dist/` to any static host (Netlify, Vercel, Cloudflare Pages…).
`public/_redirects` (Netlify) and `vercel.json` (Vercel) are included so links like `/products/indus-bracket-fan` work when opened directly.

> Prices in the demo data are examples. Replace them with your real prices before going live.
